# Intégration avec Activités mentales

Source : https://github.com/Offsidealex/Activites_mentales

Avant d'importer les questions :
1. Identifier les modules réellement proposés dans les menus et les fichiers JavaScript.
2. Vérifier pour chaque module la définition du niveau 1, les formats de réponse et les règles de correction.
3. Isoler les générateurs purs ou construire des adaptateurs sans modifier le dépôt source.
4. Vérifier les licences et dépendances avant réutilisation.
5. Ajouter des tests unitaires sur les cas limites (décimaux, fractions, arrondis, unités).
6. Comparer les résultats aux exercices originaux.

Les 11 bâtiments du prototype actuel sont une liste provisoire, **pas un inventaire exhaustif**.
