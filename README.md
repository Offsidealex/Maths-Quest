# Maths Quest — L’Académie des Nombres

Jeu de mathématiques pour les élèves, avec quatre niveaux mêlant calcul, fractions, géométrie, statistiques, probabilités et algèbre.

🎮 [Jouer à Maths Quest](https://offsidealex.github.io/Maths-Quest/)

## Version publique 0.3.86

Les niveaux 1 à 4 sont disponibles. Chaque épreuve comporte dix questions ; huit bonnes réponses permettent de poursuivre. Les niveaux se débloquent dans l’ordre de progression. Les raccourcis de changement de niveau réservés au développement sont retirés.

La connexion utilise le compte Activités mentales. La classe UE est disponible dans la liste des classes. Le mode invité permet également de jouer.

## Niveaux

1. Les bases de l’Académie
2. La Cour des Savoirs
3. L’Observatoire royal
4. La Forge des Nombres

Les prochains niveaux seront publiés au fur et à mesure de leur finalisation.

## Publication

La branche `main` contient la version publique et déclenche la publication sur GitHub Pages. Une seule version est diffusée aux élèves.
